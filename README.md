# Customer Behaviour Analysis Dashboard

An interactive data analytics project developed using Python, SQL, and Power BI to analyze customer purchasing behaviour, customer segments, product performance, subscription behaviour, discounts, and revenue trends.

## Technologies Used

- Python
- SQL
- Power BI

## Project Overview

This project focuses on analyzing customer purchasing data and transforming it into meaningful business insights through data analysis, SQL queries, and interactive Power BI visualizations.

## Analysis Performed

- Gender-wise revenue analysis
- Customer spending analysis
- Discount usage analysis
- Product review analysis
- Shipping type comparison
- Subscriber vs. non-subscriber analysis
- Customer segmentation
- Product performance analysis
- Repeat customer analysis
- Age-group revenue analysis

## Project Files

- `customer_behavior.sql` – SQL queries used for customer and business analysis
- `customer_behavior.pbix` – Power BI dashboard
- `python/` – Python analysis and preprocessing code
- `screenshots/` – Dashboard screenshots
- `data/` – Dataset/sample data

## SQL Analysis

The SQL analysis covers customer revenue, discounts, product ratings, shipping types, subscriptions, customer segmentation, product popularity, repeat buyers, and revenue by age group.

## Power BI Dashboard

The Power BI dashboard is used to visualize customer behaviour and business insights interactively.
